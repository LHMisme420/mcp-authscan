# MCP AuthScan CLI

Security scanner for authorized MCP server assessments. Python 3.11 or newer
is required.

From the repository root, install the CLI with:

```bash
pip install -e .
mcp-authscan --help
```

Build release distributions from the repository root with:

```bash
python3 -m build --outdir ./dist
```

For usage, authorization requirements, examples, and the web application, see
the [repository documentation](https://github.com/LHMisme420/mcp-authscan).
