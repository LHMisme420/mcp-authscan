# Security Policy

## Reporting a Vulnerability
Report suspected vulnerabilities in mcp-authscan to lhmisme2011@gmail.com.
Please do not open public issues for security reports. Expect an initial
response within 7 days. Coordinated disclosure preferred; credit given
unless you request otherwise.

## Scope
mcp-authscan is a static analysis tool. It reads target source code and
emits findings; it does not execute target code. Reports about the scanner's
own behavior (false negatives on seed findings, unsafe file handling during
a scan) are in scope.
